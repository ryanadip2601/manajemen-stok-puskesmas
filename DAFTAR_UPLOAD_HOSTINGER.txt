BAGIAN 4: PERINTAH SETELAH UPLOAD
================================================================================

Jalankan perintah berikut di terminal Hostinger (SSH atau File Manager Terminal):

1. Masuk ke direktori project:
   cd public_html

2. Jalankan migrasi database:
   php artisan migrate

3. Clear cache:
   php artisan config:cache
   php artisan route:cache
   php artisan view:clear

4. Set permission storage (jika perlu):
   chmod -R 775 storage
   chmod -R 775 bootstrap/cache
